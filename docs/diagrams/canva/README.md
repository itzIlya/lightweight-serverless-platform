# Canva-Friendly Vector Diagrams

These SVG files are designed for Canva import.

They intentionally use:

- simple rectangles, circles, lines, polygons, and text
- inline `fill` and `stroke` colors
- no CSS classes
- no gradients
- no filters
- no SVG marker arrows

That makes them easier to recolor inside Canva after import. If Canva imports
them as grouped elements, ungroup the SVG and select individual boxes/arrows to
change colors.

Files:

- `platform_architecture_canva.svg`
- `main_services_canva.svg`
- `current_deployment_architecture_canva.svg`
- `build_flow_canva.svg`
- `api_request_invocation_flow_canva.svg`
