# Platform Diagram Assets

These SVG diagrams are reusable in the bachelor report, slide deck, README, or frontend documentation.

| Diagram | File |
| --- | --- |
| Platform architecture | `platform_architecture.svg` |
| Main services | `main_services.svg` |
| Current deployment architecture | `current_deployment_architecture.svg` |
| Build flow | `build_flow.svg` |
| API request invocation flow | `api_request_invocation_flow.svg` |
| Detailed build image flow | `build_image_flow_detailed.mmd` |

The diagrams are plain SVG files, so they can be opened in a browser, imported into presentation tools, or converted for LaTeX with Inkscape if needed.

The detailed build image flow is Mermaid source. It can be rendered by GitHub,
Mermaid Live, Obsidian, or `mmdc` if Mermaid CLI is installed.
